# 가상 주식 투자 게임

10개 종목에 가상으로 투자하는 5턴짜리 게임입니다. 시작 자금은 1,000,000원, 모든 종목의 시작 단가는 5,000원입니다.
모든 턴이 끝나면 보유 주식이 자동으로 매도되고, 최종 금액 순위가 DB에 저장됩니다.

## 요구 사항

- **Node.js 22.13 이상** (내장 `node:sqlite` 사용)
- 외부 패키지 설치는 필요 없습니다. `npm install`을 하지 않아도 됩니다.

## 실행

```bash
npm start
```

브라우저에서 http://localhost:3456 을 엽니다. Windows에서는 `start.bat`을 더블클릭해도 됩니다.
포트를 바꾸려면 `PORT` 환경변수를 지정하세요. 데이터는 프로젝트 폴더의 `game.db`에 저장되며, 위치는 `DB_PATH`로 바꿀 수 있습니다.

## 테스트

```bash
npm test
```

서버를 임시 DB와 비어 있는 포트로 띄워서 HTTP로만 검증하므로 실제 `game.db`에는 영향이 없습니다.

## 게임 규칙

1. 종목을 선택하고 수량을 입력해 **매수** / **매도**합니다.
2. **턴 종료**를 누르면 종목별 시세가 -20% ~ +25% 범위에서 무작위로 바뀝니다. 아무 거래도 하지 않았다면 한 번 더 확인합니다.
3. 5턴이 끝나면 보유 주식을 모두 현재가로 매도하고 최종 금액으로 랭킹이 저장됩니다.
4. 게임 도중 새로고침해도 진행 중이던 게임이 이어집니다.

## AI 추천 (선택)

`.env.example`을 `.env`로 복사해 `OPENROUTER_API_KEY`를 채우면 게임 화면에서 "AI 추천 받기" → "추천대로 실행"을 쓸 수 있습니다. 키가 없으면 해당 기능만 503으로 안내됩니다.

구조와 개발 메모는 [CLAUDE.md](CLAUDE.md)를 참고하세요.
